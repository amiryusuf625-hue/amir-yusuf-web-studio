# Amir Yusuf Web Development Studio

A responsive React + Vite starter website for Amir Yusuf Web Development Studio.

## Included
- Home, About, Services, Portfolio and Contact sections
- Responsive mobile navigation
- Portfolio category filters
- Project enquiry form that prepares an email using the visitor's email app
- Modern blue-and-white visual identity
- Clearly labelled demonstration portfolio concepts

## Run locally
1. Install Node.js (LTS).
2. Open a terminal in this project folder.
3. Run npm install.
4. Run npm run dev.
5. Open the local URL printed by Vite.

## Build for deployment
Run npm run build. The production website is generated in the dist folder.

## Before publishing
- Replace hello@amirwebstudio.com in main.jsx with your real business email.
- Add your real social links.
- Replace or update the sample project descriptions with your own work.
- The contact form currently opens the visitor's email application. It does not yet store enquiries in a database.
- No admin dashboard or authentication is included in this first frontend stage. These will be added when Supabase is configured.

## Next steps
Connect the project to GitHub, then connect Supabase for secure enquiry storage, administrator authentication and project management.
